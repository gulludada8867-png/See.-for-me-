# SeeForMe – AI visual assistance (PS04 prototype)

Single-page website. Everything is in `index.html` and runs in the browser.

**Live site:** GitHub repo → Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
Your site appears at `https://<your-username>.github.io/<repo-name>/`.

- Free mode: reads text from signs/labels in the browser (Tesseract.js) and answers follow-ups.
- Optional: paste your own OpenAI or Anthropic key on the page for object and scene recognition.
- Camera needs HTTPS (GitHub Pages is HTTPS). Voice input works best in Chrome/Edge.
- Prototype only; not a navigation or safety aid.
